Issue #1: Password Toggle Button Not Working

CRITICAL JavaScript

Symptom: Clicking the eye icon () didn't show/hide password

Root Cause: JavaScript selector mismatch

Before (BROKEN)

// assets/js/login.js
function initializePasswordToggle() {
  const passwordInput = document.getElementById('password');
  const toggleButton = document.querySelector('.toggle-password');
  //  Looking for CLASS selector
  
  if (!passwordInput || !toggleButton) return;
  //  Button never found, returns early
}

After (FIXED)

// assets/js/login.js
function initializePasswordToggle() {
  const passwordInput = document.getElementById('password');
  const toggleButton = document.getElementById('togglePassword');
  //  Correct ID selector
  
  if (!passwordInput || !toggleButton) {
    console.warn('Password toggle elements not found');
    return;
  }
  //  Button found, functionality works
}
Fix Applied: Changed selector from .toggle-password to #togglePassword
File: assets/js/login.js (line 70)

Issue #3: Admin Approvals Page Network Error

HIGH SQL

Symptom: "Error: Network response was not ok" in admin panel

Root Cause: Database column name mismatch

Before (BROKEN)

// admin/api/get_pending_accounts.php
SELECT 
    h.id,
    h.name,
    h.email,
    h.contact,  //  Column doesn't exist!
    h.address
FROM homeowners h
WHERE h.account_status = 'pending'

// SQL Error: Unknown column 'h.contact'

After (FIXED)

// admin/api/get_pending_accounts.php
SELECT 
    h.id,
    h.name,
    h.email,
    h.contact_number,  //  Correct column name
    h.address
FROM homeowners h
WHERE h.account_status = 'pending'

//  Query executes successfully
Fix Applied: Changed column from contact to contact_number
File: admin/api/get_pending_accounts.php (line 20)
Database Schema: Confirmed column is contact_number in homeowners table
